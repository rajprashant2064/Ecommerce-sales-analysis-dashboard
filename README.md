# E-Commerce Sales Analysis Dashboard

An end-to-end **E-Commerce Sales Analysis** project using **Python, Pandas, SQL, and Power BI** to clean, analyze, visualize, and present sales and profitability data from the Superstore dataset.

## 📌 Project Overview

This project analyzes e-commerce sales performance across multiple business dimensions including time, category, sub-category, region, state, customer segment, shipping mode, product, customer, and discount.

The project follows an end-to-end data analytics workflow:

**Data Cleaning → Python/Pandas Analysis → SQL Business Analysis → Power BI Dashboard → Business Insights**

The objective is to transform raw transactional data into meaningful KPIs, trends, comparisons, and business-oriented insights.

## 📊 Dataset

The cleaned Superstore dataset contains:

- **9,994** transaction records
- **5,009** unique orders
- **793** unique customers
- **23** columns
- **Total Sales:** ₹2.30M
- **Total Profit:** ₹286K

## 🎯 Business Objectives

- Analyze overall sales and profit performance
- Identify yearly and monthly sales trends
- Compare product categories and sub-categories
- Analyze regional and state-level performance
- Evaluate customer segments
- Analyze shipping mode performance
- Identify top-performing products and customers
- Examine discount and profitability relationships
- Identify loss-making sub-categories
- Calculate year-over-year sales growth
- Calculate profit margins by category
- Present analysis through an interactive Power BI dashboard
